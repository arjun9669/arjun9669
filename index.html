    RETRIEVAL PIPELINE

    01 · Extract→02 · Chunk→03 · Rank→04 · Cite

    Documents are processed inside your browser. A deterministic BM25-style lexical ranking finds relevant overlapping chunks, then answers quote evidence directly from the source material. No document uploads, LLM prompts, cloud inference, or fabricated accuracy scores are involved in the core demo.

    ENGINEERING NOTES

    • Private by default — no shared document storage
    • Inspectable — ranking source and tests in repository
    • Honest limitations — keyword matching is not semantic reasoning
    • PDF dependency — PDF.js library loaded from a third-party CDN
